# Shelfwise Library System

A robust console-based library management system developed in Java, focusing on Object-Oriented Programming (OOP), collection handling, and business logic automation.

> Note on Project Evolution: This repository represents the initial foundation and MVP of the system. As my studies in back-end engineering progress, this project will be systematically refactored, scaled, and enhanced with advanced architectural patterns, database persistence, and robust error handling.

---

## Features

- Book Management: Register books with title, author, ISBN, and availability status.
- Member Directory: Manage library members with registration tracking, full names, and contact emails.
- Automated Loan Processing: Loan transaction logic linking books and members.
- Smart Date Calculation: Automatically records pickup dates and scheduled returns using java.time.
- Input Validation: Null-safety checks to prevent runtime errors.

---

## Technologies Applied

- Java
- Object-Oriented Programming (OOP)
- Collections Framework (ArrayList)
- Java Time API
